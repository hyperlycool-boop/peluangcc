# Ruang Peluang — fondasi v0.1
Cakupan: Phase 0 dan Pertemuan 1. Next.js App Router + TypeScript strict.

```sh
npm install
npm run dev
```
Buka http://127.0.0.1:3000 dan http://127.0.0.1:3000/styleguide.

```sh
npm test
npm run typecheck
npm run build
npm run validate:materi
```
validate:materi pada tahap ini memeriksa model himpunan dan metadata sitasi; belum merupakan audit seluruh kurikulum.

Dokumen: docs/DRAF_PERTEMUAN_1.md, docs/LAPORAN_PROYEK_WEBSITE_PEMBELAJARAN.md, docs/ARSITEKTUR.md, docs/VERIFIKASI.md.
